# SaveVault-DOC

Documentation site source for **SaveVault — Versioned Save System with Migration, Recovery & Sync** by Decnet Games.

Built with Jekyll + [Just the Docs](https://just-the-docs.com/) (loaded via `remote_theme`) and published with GitHub Pages at:

**https://decnet-games.github.io/SaveVault-DOC/**

## Layout

- `index.md` — Home
- `docs/` — Getting Started, Installation, Quick Start, The Home Window, One-Click Setup, Storage Status, Versioned Schemas, Migration Centre, Atomic Persistence, Integrity Sealing, Backups & Recovery, Save Health & Diagnostics, Sync Lab, Cloud Backends & Merge Resolution, Steam Cloud, The Wayfarer Sample, Settings, What v1 Is Not, FAQ, Troubleshooting, Changelog, Support
- No `assets/` media in this tree: the pages are written so they do not depend on any image (the MergeGuard-DOC precedent). Screenshots join the tree only from real Editor captures — documentation never ships invented imagery.

SaveVault itself is sold exclusively through the Unity Asset Store (publisher: Decnet Games). Nothing in this repository is the product — this repo is documentation only.

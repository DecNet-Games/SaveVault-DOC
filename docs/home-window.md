# The Home Window
{: .no_toc }

**Tools → Decnet Games → SaveVault** opens SaveVault Home. Everything SaveVault does in the Editor lives in this one window, in six sections.

## Welcome

The landing section: one-click setup and verification. The setup report names what was verified, line by line — see [One-Click Setup]({{ site.baseurl }}/docs/one-click-setup/).

## Storage Status

Every slot, with its version and seal state. This is where you see, at a glance, which saves exist, which format version each one is stored at, and whether each seal verifies. See [Storage Status]({{ site.baseurl }}/docs/storage-status/).

## Migration Centre

The registered migration chains, and which stored saves still need migration. SaveVault's own registered chains render here — player → v3 (2 steps), inventory → v2 (1 step), world → v3 (2 steps) — alongside your game's sections. See [Migration Centre]({{ site.baseurl }}/docs/migration-centre/).

## Save Health & Diagnostics

Backups, the quarantine, and one-click fault simulations (bit-flip, torn temp, tamper) so recovery is testable before your players find it. See [Save Health & Diagnostics]({{ site.baseurl }}/docs/save-health-and-diagnostics/).

## Sync Lab

The two-device sync surface: Device A and Device B storage roots, the cloud backend's seed state, and divergence review for your local-first sync setup. It is a review surface — read [Sync Lab]({{ site.baseurl }}/docs/sync-lab/) for exactly what it does and does not do.

## Settings

Backup retention, tamper policy, sync trigger, autosave interval, and sync throttle. See [Settings]({{ site.baseurl }}/docs/settings/).

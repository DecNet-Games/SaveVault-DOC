# Support
{: .no_toc }

## Email

**support@decnetgames.com** — the support address for SaveVault and every Decnet Games product. When you write about a recovery or a migration, include what the window shows: the setup report from [One-Click Setup]({{ site.baseurl }}/docs/one-click-setup/), the slot's version and seal state from [Storage Status]({{ site.baseurl }}/docs/storage-status/), and the recovery report text — those three make a report answerable instead of speculative.

## Before you write

- [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) covers the states SaveVault reports about itself: verification failures, tamper detections, the Steamworks.NET probe, and migration candidates.
- [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/) is the boundary list — if the thing you need is on it (a live-Steam guarantee, a simulation runner, a sample scene), it is a v1 boundary, not a bug.
